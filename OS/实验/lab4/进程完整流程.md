## 完整的内核线程创建与执行流程

### 阶段一：系统初始化

```
系统启动 (kern_init)
    ↓
proc_init() - 进程系统初始化
    ↓
├─ 初始化进程链表 list_init(&proc_list)
├─ 初始化哈希表 for(i=0; i<1024; i++) list_init(hash_list+i)
    ↓
创建第0号进程 idleproc (空闲进程)
    ↓
alloc_proc()
    ├─ kmalloc(sizeof(proc_struct)) - 分配内存
    ├─ state = PROC_UNINIT
    ├─ pid = -1
    ├─ runs = 0
    ├─ kstack = 0
    ├─ need_resched = 0
    ├─ parent = NULL
    ├─ mm = NULL
    ├─ memset(&context, 0)
    ├─ tf = NULL
    ├─ pgdir = boot_pgdir_pa
    ├─ flags = 0
    └─ memset(name, 0)
    ↓
手动设置 idleproc
    ├─ pid = 0
    ├─ state = PROC_RUNNABLE
    ├─ kstack = (uintptr_t)bootstack
    ├─ need_resched = 1
    ├─ name = "idle"
    └─ nr_process = 1
    ↓
current = idleproc (设置当前进程)
```

### 阶段二：创建第一个内核线程 (initproc)

```
kernel_thread(init_main, "Hello world!!", 0)
    ↓
┌─────────────────────────────────────────┐
│  构造临时 trapframe tf                    │
├─────────────────────────────────────────┤
│  memset(&tf, 0)          - 清零          │
│  tf.gpr.s0 = fn地址      - 保存函数指针   │
│  tf.gpr.s1 = arg地址     - 保存参数       │
│  tf.status = ...         - 设置状态寄存器 │
│    = read_csr(sstatus)   读取当前状态    │
│    | SSTATUS_SPP          设置为内核态    │
│    | SSTATUS_SPIE         返回后开中断    │
│    & ~SSTATUS_SIE         当前禁止中断    │
│  tf.epc = kernel_thread_entry - 设置返回地址│
└─────────────────────────────────────────┘
    ↓
do_fork(CLONE_VM, 0, &tf)
    ↓
检查进程数 (nr_process < MAX_PROCESS?)
    ↓ 是
┌─────────────────────────────────────────┐
│  1. alloc_proc() - 分配新进程结构        │
├─────────────────────────────────────────┤
│     返回初始化好的 proc_struct           │
│     (所有字段都是初始值)                 │
└─────────────────────────────────────────┘
    ↓
proc->parent = current (设置父进程为idleproc)
    ↓
┌─────────────────────────────────────────┐
│  2. setup_kstack(proc) - 分配内核栈      │
├─────────────────────────────────────────┤
│     page = alloc_pages(KSTACKPAGE)      │
│     分配 2 页 (8KB) 作为内核栈           │
│     proc->kstack = page2kva(page)       │
│     返回内核栈的虚拟地址                 │
└─────────────────────────────────────────┘
    ↓
┌─────────────────────────────────────────┐
│  3. copy_mm(CLONE_VM, proc)             │
├─────────────────────────────────────────┤
│     内核线程不需要独立内存空间           │
│     assert(current->mm == NULL)         │
│     直接返回 0                           │
└─────────────────────────────────────────┘
    ↓
┌─────────────────────────────────────────┐
│  4. copy_thread(proc, 0, &tf)           │
│     设置新进程的执行环境                 │
├─────────────────────────────────────────┤
│  计算 trapframe 在内核栈中的位置：       │
│  proc->tf = proc->kstack + KSTACKSIZE   │
│              - sizeof(trapframe)        │
│     ↓                                   │
│  ┌─────────────────────────┐            │
│  │ 内核栈布局 (8KB)         │            │
│  ├─────────────────────────┤ ← kstack+8KB│
│  │  trapframe (保存寄存器)  │            │
│  │  - gpr.s0 = fn          │            │
│  │  - gpr.s1 = arg         │            │
│  │  - gpr.a0 = 0 ★设为0    │            │
│  │  - gpr.sp = tf地址      │            │
│  │  - status = ...         │            │
│  │  - epc = kernel_thread_entry│        │
│  ├─────────────────────────┤ ← proc->tf │
│  │                         │            │
│  │   空闲栈空间             │            │
│  │                         │            │
│  └─────────────────────────┘ ← kstack   │
│     ↓                                   │
│  复制传入的 tf 到 proc->tf               │
│  *(proc->tf) = *tf                      │
│     ↓                                   │
│  修改子进程的返回值：                     │
│  proc->tf->gpr.a0 = 0                   │
│  (父进程会得到子进程pid，子进程得到0)     │
│     ↓                                   │
│  设置栈指针：                            │
│  proc->tf->gpr.sp = (uintptr_t)proc->tf │
│     ↓                                   │
│  设置进程上下文 context：                │
│  proc->context.ra = forkret             │
│  proc->context.sp = proc->tf            │
│                                         │
│  context 保存的是 switch_to 恢复时的状态 │
│  - ra: 返回地址，会跳到 forkret()        │
│  - sp: 栈指针，指向 trapframe           │
└─────────────────────────────────────────┘
    ↓
┌─────────────────────────────────────────┐
│  5. 插入进程管理结构 (关中断保护)        │
├─────────────────────────────────────────┤
│  local_intr_save(intr_flag) - 关中断    │
│     ↓                                   │
│  proc->pid = get_pid() - 分配PID        │
│     ↓                                   │
│  ┌──────────────────────────┐           │
│  │ get_pid() 详细过程：      │           │
│  ├──────────────────────────┤           │
│  │ static last_pid = MAX_PID│ 静态变量  │
│  │ static next_safe=MAX_PID │           │
│  │   ↓                      │           │
│  │ if(++last_pid>=MAX_PID)  │           │
│  │    last_pid = 1          │ 从1开始   │
│  │   ↓                      │           │
│  │ if(last_pid>=next_safe)  │           │
│  │    遍历 proc_list:       │           │
│  │    - 检查是否冲突         │           │
│  │    - 更新 next_safe      │           │
│  │   ↓                      │           │
│  │ return last_pid          │ 返回唯一PID│
│  └──────────────────────────┘           │
│     ↓                                   │
│  hash_proc(proc) - 加入哈希表            │
│     计算哈希值: hash32(pid, 10)          │
│     插入到 hash_list[哈希值] 链表         │
│     ↓                                   │
│  list_add(&proc_list, &proc->list_link) │
│     加入全局进程链表                     │
│     ↓                                   │
│  nr_process++ - 进程计数加1              │
│     ↓                                   │
│  local_intr_restore(intr_flag) - 开中断 │
└─────────────────────────────────────────┘
    ↓
┌─────────────────────────────────────────┐
│  6. wakeup_proc(proc)                   │
├─────────────────────────────────────────┤
│     assert(proc->state == PROC_UNINIT)  │
│     proc->state = PROC_RUNNABLE         │
│     新进程变为可运行状态                 │
└─────────────────────────────────────────┘
    ↓
┌─────────────────────────────────────────┐
│  7. 返回子进程 PID                       │
├─────────────────────────────────────────┤
│     ret = proc->pid                     │
│     父进程(idleproc)得到子进程PID=1      │
└─────────────────────────────────────────┘
    ↓
proc_init() 继续：
    initproc = find_proc(1)
    set_proc_name(initproc, "init")
    ↓
至此，系统中有两个进程：
    - idleproc (pid=0, 当前运行)
    - initproc (pid=1, 等待调度)
```

### 阶段三：进程调度与切换

```
cpu_idle() - idleproc 的主循环
    ↓
while(1) {
    if (current->need_resched) {  // idleproc.need_resched=1
        schedule()
    }
}
    ↓
┌─────────────────────────────────────────┐
│  schedule() - 调度器                     │
├─────────────────────────────────────────┤
│  找到下一个 RUNNABLE 进程                │
│  next = initproc (pid=1)                │
│     ↓                                   │
│  调用 proc_run(next)                    │
└─────────────────────────────────────────┘
    ↓
proc_run(initproc)
    ↓
if (proc != current) {  // initproc != idleproc
    ↓
┌─────────────────────────────────────────┐
│  进程切换的关键步骤                      │
├─────────────────────────────────────────┤
│  bool intr_flag;                        │
│  prev = current  (idleproc)             │
│  next = proc     (initproc)             │
│     ↓                                   │
│  1. local_intr_save(intr_flag)          │
│     关闭中断，保护切换过程               │
│     ↓                                   │
│  2. current = proc                      │
│     更新当前进程指针为 initproc          │
│     ↓                                   │
│  3. lsatp(next->pgdir)                  │
│     切换页表 (内核线程都用同一个页表)     │
│     写入 satp 寄存器                     │
│     ↓                                   │
│  4. switch_to(&prev->context,           │
│                &next->context)          │
│     【关键】汇编实现的上下文切换          │
└─────────────────────────────────────────┘
    ↓
┌─────────────────────────────────────────┐
│  switch_to() 汇编代码详解 (switch.S)     │
├─────────────────────────────────────────┤
│  保存当前进程(idleproc)的寄存器：        │
│  sd ra, 0(a0)   # 保存返回地址           │
│  sd sp, 8(a0)   # 保存栈指针             │
│  sd s0, 16(a0)  # 保存 s0-s11 callee寄存器│
│  sd s1, 24(a0)                          │
│  ...                                    │
│  sd s11, 88(a0)                         │
│     ↓                                   │
│  恢复新进程(initproc)的寄存器：          │
│  ld ra, 0(a1)   # 恢复 ra = forkret地址  │
│  ld sp, 8(a1)   # 恢复 sp = trapframe地址│
│  ld s0, 16(a1)  # 恢复 s0-s11           │
│  ld s1, 24(a1)                          │
│  ...                                    │
│  ld s11, 88(a1)                         │
│     ↓                                   │
│  ret            # 跳转到 ra (forkret)    │
└─────────────────────────────────────────┘
    ↓
这里发生了"魔法"：
    - 执行 ret 指令
    - CPU 跳转到 ra 寄存器的地址
    - ra = forkret (在 copy_thread 中设置的)
    ↓
【新进程 initproc 开始执行】
    ↓
forkret()
    ↓
┌─────────────────────────────────────────┐
│  forkret() 函数                          │
├─────────────────────────────────────────┤
│  static void forkret(void) {            │
│      forkrets(current->tf);             │
│  }                                      │
│     ↓                                   │
│  current = initproc                     │
│  current->tf 指向内核栈顶的 trapframe    │
└─────────────────────────────────────────┘
    ↓
forkrets(trapframe *tf)  [在 trapentry.S 实现]
    ↓
┌─────────────────────────────────────────┐
│  forkrets() 汇编代码 (trapentry.S)       │
├─────────────────────────────────────────┤
│  从 trapframe 恢复所有寄存器：           │
│  ld sp, tf                # sp 指向tf    │
│  ld ra, 40(sp)            # 恢复 ra      │
│  ld gp, 48(sp)            # 恢复 gp      │
│  ld tp, 56(sp)            # 恢复 tp      │
│  ...                                    │
│  ld s0, 64(sp)  ← fn地址                │
│  ld s1, 72(sp)  ← arg地址               │
│  ...                                    │
│  ld t0, status(sp)        # 恢复 sstatus │
│  csrw sstatus, t0         # 写入寄存器   │
│  ld t0, epc(sp)           # 恢复 sepc    │
│  csrw sepc, t0  ← kernel_thread_entry   │
│     ↓                                   │
│  sret               # 从S模式返回        │
│     【特权级切换指令】                   │
│     - PC = sepc (跳转到kernel_thread_entry)│
│     - 特权级 = sstatus.SPP (保持S模式)   │
│     - 中断使能 = sstatus.SPIE (开启中断) │
└─────────────────────────────────────────┘
    ↓
kernel_thread_entry  [在 entry.S 实现]
    ↓
┌─────────────────────────────────────────┐
│  kernel_thread_entry 汇编代码            │
├─────────────────────────────────────────┤
│  .globl kernel_thread_entry             │
│  kernel_thread_entry:                   │
│      move a0, s1      # arg → a0 (参数) │
│      jalr s0          # 调用 fn(arg)    │
│                       # s0=函数地址      │
│      jal do_exit      # fn返回后退出     │
└─────────────────────────────────────────┘
    ↓
【终于！】执行用户定义的线程函数
    ↓
init_main(void *arg)
    ↓
┌─────────────────────────────────────────┐
│  init_main() - 第一个内核线程的代码      │
├─────────────────────────────────────────┤
│  static int init_main(void *arg) {      │
│      cprintf("这是 initproc, pid=%d\n", │
│              current->pid);             │
│      cprintf("To U: \"%s\".\n", arg);   │
│      cprintf("To U: \"Bye, Bye.\"\n");  │
│      return 0;                          │
│  }                                      │
└─────────────────────────────────────────┘
    ↓
函数返回 0
    ↓
回到 kernel_thread_entry 的 jalr 下一行
    ↓
jal do_exit  # 进程退出
    ↓
do_exit(0)
    ↓
panic("process exit!!.\n")  # 本实验未完整实现
```

### 总结：完整的调用链

```
系统启动
  → kern_init()
    → proc_init()
      → alloc_proc() [创建idleproc]
      → kernel_thread(init_main, ...) [创建initproc]
        → 构造trapframe (s0=fn, s1=arg, epc=kernel_thread_entry)
        → do_fork()
          → alloc_proc() [分配initproc结构]
          → setup_kstack() [分配8KB内核栈]
          → copy_mm() [内核线程不需要]
          → copy_thread() [复制trapframe, 设置context.ra=forkret]
          → get_pid() [分配PID=1]
          → hash_proc() [加入哈希表]
          → list_add() [加入进程链表]
          → wakeup_proc() [state=RUNNABLE]
        → 返回pid=1
      → initproc = find_proc(1)
    → cpu_idle() [idleproc主循环]
      → schedule()
        → proc_run(initproc)
          → 关中断
          → current = initproc
          → lsatp() [切换页表]
          → switch_to(&idleproc->context, &initproc->context)
            [汇编] 保存idleproc寄存器
            [汇编] 恢复initproc寄存器 (ra=forkret, sp=tf)
            [汇编] ret → 跳转到forkret
          → forkret()
            → forkrets(current->tf)
              [汇编] 从trapframe恢复所有寄存器
              [汇编] sret → 跳转到sepc (kernel_thread_entry)
              → kernel_thread_entry
                [汇编] move a0, s1 (arg→a0)
                [汇编] jalr s0 (调用fn)
                → init_main("Hello world!!")
                  → cprintf(...)
                  → return 0
                → do_exit(0)
                  → panic()
```

这就是从系统启动到第一个内核线程执行的**完整、详细**的流程！每一步都涉及精心设计的状态设置和上下文切换。
