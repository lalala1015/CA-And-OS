# GPU SIMD 利用率计算题集

## 题 1（嵌套 if，和你截图同款）

**来源**：公开讲义/练习题 "GPUs and SIMD III"（含题面与参考解）[Scribd](https://www.scribd.com/document/569760976/15)

### 题目（等价复述）

GPU 采用 SIMT：**warp=64 threads**，**SIMD lanes=64**。下面代码中，**每个线程只执行循环的一次迭代**（可理解为每个 `i` 对应一个线程），数组 `A,B,C` 均已在寄存器中（忽略访存），并且保证 `|B[i]| < 10`。该迭代静态上可数作 **6 条指令**（两次比较/分支也算指令）。

```c
for (i = 0; i < 1024; i++) {
  A[i] = B[i] * B[i];
  if (A[i] > 0) {
    C[i] = A[i] * B[i];
    if (C[i] < 0) {
      A[i] = A[i] + 1;
    }
    A[i] = A[i] - 2;
  }
}
```

**回答：**

1. 总共需要多少个 warps？
2. 该程序**最大**可能 SIMD/GPU 利用率是多少？
3. 达到最大利用率时，`B` 需要满足什么特征？（覆盖所有情况）
4. 该程序**最小**可能 SIMD/GPU 利用率是多少？
5. 达到最小利用率时，`B` 需要满足什么特征？（覆盖所有情况）

### 完整答案（含推导）

**(1) warps 数量**

共有 1024 个线程（每个 `i` 一个线程），每 warp 64 线程：

$$\text{warps} = 1024/64 = 16$$

**(2) 最大利用率**

当 warp 内**不发生分支发散**（每条被发射的指令都让 64 lanes 都 active），利用率就是 **100%**。

**(3) 达到最大利用率时 B 的特征**

关键是避免 warp 内出现"有的线程走分支体、有的不走"或"有的走内层 if、有的不走"。

注意：
- `A[i] = B[i]^2`，因此 `A[i] > 0` 等价于 `B[i] ≠ 0`
- `C[i] = B[i]^3`，因此 `C[i] < 0` 等价于 `B[i] < 0`

所以要让 warp 内一致，需要对每个**连续 64 个元素（一个 warp 的元素）**满足三种之一：

- 全部 `B = 0`（所有线程都不进外层 if）
- 全部 `B > 0`（所有线程进外层 if，但都不进内层 if）
- 全部 `B < 0`（所有线程进外层 if，也都进内层 if）

这三种都没有发散 → **100%**。

**(4) 最小利用率**

要让"很多指令被执行，但 active lanes 尽可能少"，最极端是：

- 前两条指令（`A=B*B`、比较 `A>0`）是所有线程都会做的 → 每条 **64/64**
- 让只有 **1 个线程**进入外层 if，并且也进入内层 if，这样指令 `C=A*B`、比较 `C<0`、`A=A+1`、`A=A-2` 这 4 条都只能 **1/64** active

于是总体（按整段运行的"发射指令 × lane 数"平均）：

$$\text{util} = \frac{64 \cdot 2 + 1 \cdot 4}{64 \cdot 6} = \frac{132}{384} = \frac{11}{32} \approx 34.375\%$$

**(5) 达到最小利用率时 B 的特征**

要让**只有 1 个线程**通过 `A>0`，必须让其它 63 个线程 `B=0`（因为只要 `B≠0` 就有 `A>0`）。

要让那 1 个线程还通过 `C<0`，它必须满足 `B<0`。

因此：对每个连续 64 个元素，**恰好 1 个是负数，其余 63 个全是 0**。

## 题 2（单层 if + "测得利用率反推输入分布"）

**来源**：公开讲义/练习题 "GPUs and SIMD II"（含题面与参考解）[Scribd](https://www.scribd.com/document/569760976/15)

### 题目（等价复述）

warp=64，SIMD lanes=64；每个线程执行一次迭代；无访存。静态上每线程 **4 条指令**（比较/分支+分支体 3 条 ALU）。

```c
for (i = 0; i < 1048576; i++) {
  if (B[i] < 4444) {
    A[i] = A[i] * C[i];
    B[i] = A[i] + B[i];
    C[i] = B[i] + 1;
  }
}
```

**问：**

1. 需要多少 warps？
2. 若测得 SIMD 利用率为 67/256，能推出 A、B、C 各需要满足什么？
3. 是否可能达到 100% 利用率？若能，B 需要怎样？
4. 是否可能达到 25% 利用率？若不能，说明原因。

### 完整答案

**(1) warps 数量**

$$\text{warps} = 1048576/64 = 16384$$

**(2) 利用率反推**

设每个 warp 中满足 `B<4444` 的线程数为 k。

- 比较/分支那条指令：64 个线程都 active → 64
- 分支体 3 条指令：只有那 k 个线程 active → 每条 k

总 active-lane 计数：64+3k；总"指令×lanes"是 4×64=256。

$$\text{util} = \frac{64+3k}{256} = \frac{67}{256} \Rightarrow 64+3k=67 \Rightarrow k=1$$

所以结论：**每 64 个连续的 B 元素里恰好 1 个 < 4444，其余 63 个 ≥ 4444**；A、C 对控制流无影响 → **无约束**。

**(3) 100% 是否可能？**

可以。

- 若每个 warp 都满足 k=0（全都 ≥4444），分支体完全不执行 → 发射的指令都 64/64 active → 100%
- 或每个 warp 都满足 k=64（全都 <4444），分支体 3 条也都是 64/64 → 100%

因此条件：**每个 warp 内的 B 全部同侧（全 <4444 或全 ≥4444）**。

**(4) 25% 是否可能？**

不可能。

若想压低利用率，需要 k 尽量小且 k≥1（否则就是 100%）。最小就是 k=1：

$$\text{util}_{\min} = \frac{64+3 \cdot 1}{256} = \frac{67}{256} \approx 26.17\% > 25\%$$

所以达不到 25%。

## 题 3（最经典：if(A%3==0) 版本，问能否达到某些百分比）

**来源**：公开讲义/练习题 "GPUs and SIMD I"（含题面与参考解）[Scribd](https://www.scribd.com/document/569760976/15)

### 题目（等价复述）

warp=32，lanes=32；每线程一次迭代；无访存；每条指令耗时相同。静态上每线程 2 条指令（分支判断+乘法）。

```c
for (i = 0; i < N; i++) {
  if (A[i] % 3 == 0) {   // 指令1：判断/分支
    A[i] = A[i] * B[i];  // 指令2：乘法
  }
}
```

**问：**

1. 需要多少 warps（用 N 表示）？
2. 若 A 的模式为"24 个 1 后跟 8 个 0，循环重复"，B 的模式任意（只影响数值不影响分支），求利用率。
3. 是否可能达到 100%？若能，A、B 需要怎样？
4. 是否可能达到 56.25%？若能，A 需要怎样？
5. 是否可能达到 50%？若不能，说明原因。

### 完整答案

**(1) warps 数量**

$$\text{warps} = \left\lceil \frac{N}{32}\right\rceil$$

**(2) 具体模式的利用率**

在每 32 个元素里，有 8 个 0 满足 `A%3==0`，所以每 warp 中进入分支体的线程数 k=8。

利用率：

$$\text{util} = \frac{32 + k}{32 \cdot 2} = \frac{32+8}{64} = \frac{40}{64} = 62.5\%$$

**(3) 100% 是否可能？**

可以。

- 若所有线程都满足条件（每 warp k=32），两条指令都 32/32 active → 100%
- 或若所有线程都不满足条件（每 warp k=0），第二条乘法根本不发射 → 也不会出现"部分 lane 空转" → 100%

因此：**A 要么全部可被 3 整除，要么全部不可被 3 整除；B 无要求**。

**(4) 56.25% 是否可能？**

$$56.25\% = \frac{36}{64}$$

而利用率（当 k≥1 且乘法会发射）为 (32+k)/64。令其等于 36/64：

$$32+k=36 \Rightarrow k=4$$

所以：**每个 warp 的 32 个 A 里恰好 4 个可被 3 整除**（B 无要求）。

**(5) 50% 是否可能？**

不可能。

若按"乘法确实被发射"的情形，最小 k=1：

$$\text{util}_{\min} = \frac{32+1}{64} = \frac{33}{64} \approx 51.5625\% > 50\%$$

而若 k=0，乘法不发射，利用率反而是 100%。

所以 50% 达不到。

## 题 4（CMU 真题风格：给一个测得利用率 9/40，反推 B 的分布）

**来源**：CMU 18-447 Final Exam（题面公开）[studylib.net](https://studylib.net/doc/10697271/final-exam-cmu-18-447-introduction-to-computer-architectu...)

### 题目（等价复述）

warp=32，lanes=32；每线程执行一次迭代；无访存；提示：每线程 5 条指令（分支判断 1 条 + 分支体 4 条）。

```c
for (i = 0; i < 512*1024; i++) {
  if (B[i] < 0) {
    A[i] = A[i] * C[i];
    B[i] = A[i] + B[i];
    C[i] = C[i] + 1;
    B[i] = B[i] + 1;
  }
}
```

**问：**

1. 需要多少 warps？
2. 若测得 SIMD 利用率为 9/40，能推出 A、B、C 分别需要满足什么？
3. 是否可能得到 20% 利用率？为什么？
4. 是否可能得到 100% 利用率？若能，B 需要怎样？

### 完整答案

**(1) warps 数量**

总线程数 512·1024=524288=2¹⁹。每 warp 32=2⁵：

$$\text{warps} = 2^{19}/2^{5} = 2^{14} = 16384$$

**(2) 利用率反推**

设每 warp 中满足 `B<0` 的线程数为 k。

- 分支判断指令：32 active
- 分支体 4 条：每条 k active（只对走分支的线程）

若 k≥1，总 active-lane：32+4k，总"指令×lanes"：5·32=160：

$$\text{util} = \frac{32+4k}{160} = \frac{8+k}{40} = \frac{9}{40} \Rightarrow k=1$$

所以：**每个 warp 的 32 个 B 值里恰好 1 个为负，其余 31 个非负**；A、C 对分支无影响 → **无约束**。

**(3) 20% 是否可能？**

不可能。

- 若 k=0，分支体不发射，所有发射的指令都是 32/32 active → 利用率 100%
- 若 k≥1，利用率为 (8+k)/40，最小是 k=1 得 9/40=22.5%

因此 20% 达不到。

**(4) 100% 是否可能？**

可以。

只要每个 warp 内不发散：

- 全部 `B<0`（k=32）或
- 全部 `B>=0`（k=0）

即可 100%。

## 改写后的完整题目（if-else 嵌套版本）

GPU 的利用率定义为处于 busy 状态的 GPU 核心（PE，单个计算单元）占所有 GPU 核心的比例。考虑下面的代码片段：

- 数组 **A、B、C 已经在寄存器中**（不需要从内存读写，不考虑访存延迟）。
- **每个 thread 只执行循环中的 1 次迭代**（即每个 thread 对应一个固定的 `i`，总共 `i=0.. 1023`，因此共有 1024 个 threads）。
- 该 GPU 的 **一个 warp 有 64 个 threads**，该 GPU 有 **64 个核心（PE）**。
- 假设 `B[i]` 为整数，且对所有 i 都满足：`|B[i]| < 10`。

代码如下（注意：循环内既有 if 也有 else）：

```c
for (i = 0; i < 1024; i++) {
    A[i] = B[i] * B[i] - 25;
    
    if (A[i] >= 0) {
        C[i] = A[i] + B[i];
        A[i] = A[i] - 4;
    } else {
        C[i] = A[i] - B[i];
        if (B[i] < 0)
            A[i] = A[i] + 3;
        else
            A[i] = A[i] - 3;
    }
}
```

**为便于计算，做如下指令条数约定：**

- **每条赋值/算术语句算 1 条指令**（如 `A[i]=... `、`C[i]=...`）。
- **每个 if 的条件判断（比较+分支）算 1 条指令**（执行到 if 时会发出 1 条分支指令）。
- SIMT 执行：**同一 warp 内若发生分支发散，不同路径会被串行执行**；执行某条路径时，不满足条件的 threads 对应的 PE 视为 idle。

**问题：**

1. 执行该代码段一共需要多少个 warps？
2. 执行整个代码段，**最大的 GPU 利用率**可能是多少？
3. 当获得最大 GPU 利用率时，数组 B 的取值需要满足什么特征？
4. 执行整个代码段，**最小的 GPU 利用率**可能是多少？（给出一种能达到最小值的 B 的构造思路）

### 完整答案

#### 1) 需要多少个 warps？

共有 1024 个 threads，每个 warp 64 threads：

$$\text{warps} = 1024 / 64 = 16$$

**答：16 个 warps。**

#### 2) 最大 GPU 利用率是多少？

只要 **每个 warp 内完全不发生分支发散**（所有 threads 走完全相同的控制流），则每条指令都能让 64 个 PE 全部 busy：

$$\text{利用率}_{\max} = 100\%$$

**答：最大 GPU 利用率 = 100%。**

#### 3) 获得最大 GPU 利用率时，B 的特征是什么？

先看分支条件：

- `A[i] = B[i]² - 25`
- 外层 `if (A[i] >= 0)` 等价于：`|B[i]| ≥ 5`
- 外层 `else` 等价于：`|B[i]| < 5`
- 进入外层 else 后，内层 `if (B[i] < 0)` 看的是 B 的符号

要想 **不发散**，同一个 warp 内必须保证所有 threads：

- **外层 if/else 结果一致**，并且
- 若走到内层 if-else，则 **内层判断结果也一致**

因此每个 warp 内 B 的取值可满足以下任意一种"统一模式"（三选一即可）：

1. **全走外层 if**：该 warp 内所有 `B[i]` 都满足 `|B[i]| ≥ 5`
2. **全走外层 else 且全走内层 if**：该 warp 内所有 `B[i]` 都满足 `|B[i]| < 5` 且 `B[i] < 0`
3. **全走外层 else 且全走内层 else**：该 warp 内所有 `B[i]` 都满足 `|B[i]| < 5` 且 `B[i] ≥ 0`

**答：最大利用率时，每个 warp 内 B 要让所有 thread 的分支方向完全一致（外层一致；若进入内层则内层也一致）。**

#### 4) 最小 GPU 利用率是多少？

##### 先数"warp 会执行的指令槽位（slot）"

把循环体按"可能执行的指令序列"拆开（用 slot 表示一个 warp 执行一条指令的时间片）：

- `A = B*B - 25`：1 个 slot（64 threads 全 active）
- 外层 if 判断：1 个 slot（64 全 active）
- 外层 if 路径里有 2 条赋值：2 个 slot（只有走 if 的线程 active）
- 外层 else 路径：
  - `C = A - B`：1 个 slot（走 else 的线程 active）
  - 内层 if 判断：1 个 slot（走 else 的线程 active）
  - 内层 if-else 的最后赋值：
    - 如果内层也发散（有人 B<0，有人 B≥0），则这最后一步会被拆成 **2 个 slot**（分别跑两种赋值）

所以要让利用率尽量低，你要让一个 warp **同时发生外层发散 + 内层也发散**，这样总 slot 数最多：

$$\text{总 slots} = 1 + 1 + 2 + (1 + 1 + 2) = 8$$

##### 再算"这些 slots 里一共 busy 了多少次 PE"

设一个 warp 里：

- n_T 个线程走外层 if（`|B|≥5`）
- n_F = 64 - n_T 个线程走外层 else（`|B|<5`）
- 且在 else 中内层也发散（既有 `B<0` 又有 `B≥0`，所以需要至少 n_F ≥ 2）

busy 贡献（把每个 slot 的 active 线程数加起来）：

- 前两条（计算 A、外层判断）：64 + 64 = 128
- 外层 if 的 2 条赋值：2n_T
- 外层 else 部分：
  - `C=A-B`：n_F
  - 内层判断：n_F
  - 内层两条赋值拆成 2 个 slot，但两者 active 线程数加起来仍是 n_F

合计：

$$\text{busy 总和} = 128 + 2n_T + (n_F + n_F + n_F) = 128 + 2n_T + 3n_F$$

$$= 128 + 2n_T + 3(64-n_T) = 320 - n_T$$

于是该 warp 的平均利用率：

$$U = \frac{320-n_T}{8 \times 64} = \frac{320-n_T}{512}$$

要让 U 最小，就要让 n_T 尽量大，但又要保证 else 至少有 2 个线程用于"内层发散"：

- 最小 n_F=2 ⇒ 最大 n_T=62

代入：

$$U_{\min} = \frac{320-62}{512} = \frac{258}{512} \approx 50.39\%$$

**答：最小 GPU 利用率约为 50.39%。**

##### 一种能达到最小值的 B 构造（每个 warp 都这样放）

在每个 warp 的 64 个元素里：

- 62 个取 `|B|≥5`（例如全取 5 或 6）⇒ 走外层 if
- 剩下 2 个取 `|B|<5`，并且一个负一个非负（例如 -1 和 +1）⇒ 走外层 else，且内层也发散

这样就能实现"外层发散 + 内层发散"，达到上面的最小值。

## 总结

本文档涵盖了 GPU SIMD 利用率计算的典型问题类型：

1. **嵌套 if 语句**：需要考虑多层分支发散
2. **利用率反推**：根据测得的利用率推算输入数据分布
3. **极值分析**：计算最大/最小可能利用率及其达成条件
4. **if-else 结构**：需要考虑两个分支路径都可能执行的情况

关键概念：

- **分支发散（Branch Divergence）**：同一 warp 内不同线程走不同控制流路径
- **SIMT 执行模型**：不同路径串行执行，未激活线程对应的 PE 空闲
- **利用率计算**：活跃 PE 数 / 总 PE 数的平均值

## 改写后的完整题目（含 else if）

GPU 的利用率定义为处于 busy 状态的 GPU 核心（PE，单个计算单元）占所有 GPU 核心的比例。考虑如下代码片段：

**前提条件：**

- 数组 **A、B、C 已经在寄存器中**（不考虑访存/缓存/内存延迟）。
- **每个 thread 只执行循环中的 1 次迭代**（即每个 thread 对应一个固定的 i，总共有 `i=0.. 1023` 共 1024 个 threads）。
- 一个 **warp 有 64 个 threads**，该 GPU 有 **64 个核心（PE）**。
- 假设 `B[i]` 为整数，且对所有 i 都满足：`|B[i]| < 10`。

**代码如下：**

```c
for (i = 0; i < 1024; i++) {
    A[i] = B[i] * B[i] - 36;
    
    if (A[i] > 0) {
        C[i] = A[i] + B[i];
        A[i] = A[i] - 1;
    } else if (A[i] == 0) {
        C[i] = B[i];
    } else {
        C[i] = A[i] - B[i];
        if (B[i] < 0)
            A[i] = A[i] + 2;
        else
            A[i] = A[i] - 2;
    }
}
```

**为便于计算，采用如下"指令槽位（slot）"计数规则（用于算利用率）：**

- **每条赋值/算术语句算 1 条指令（占 1 个 slot）**
- **每个 if 的条件判断（比较+分支）算 1 条指令（占 1 个 slot）**
- SIMT：同一 warp 内发生分支发散时，不同路径**串行执行**；执行某一路径时，不走该路径的 threads 对应的 PE 视为 idle。

**问题：**

1. 执行该代码段一共需要多少个 warps？
2. 执行整个代码段，**最大的 GPU 利用率**可能是多少？
3. 当获得最大 GPU 利用率时，数组 B 的值应具有什么特征？
4. 执行整个代码段，**最小的 GPU 利用率**可能是多少？并给出一种能达到该最小值的 B 的构造思路（描述每个 warp 内怎么放值即可）。

## 完整答案

### 1) 需要多少个 warps？

总 threads 数 1024，每 warp 64：

$$\text{warps} = 1024/64 = 16$$

**答：16 个 warps。**

---

### 2) 最大 GPU 利用率

若每个 warp 内**不发生任何分支发散**（所有 threads 完全走同一控制流），则每个 slot 都能让 64 个 PE 全 busy：

$$U_{\max} = 100\%$$

**答：最大 GPU 利用率 = 100%。**

---

### 3) 取得最大 GPU 利用率时，B 的特征

**先把条件化简：**

- `A = B² - 36`
- `A > 0` ⇔ `B² > 36` ⇔ `|B| ≥ 7`（因为 B 是整数）
- `A == 0` ⇔ `|B| = 6`
- `A < 0` ⇔ `|B| ≤ 5`

**要不发散，同一 warp 内必须：**

- 外层三路（if / else if / else）所有 threads 结果一致；
- 若走到 `else`，内层 `if (B<0) else` 也要一致（同号）。

**因此每个 warp 内 B 满足下面任意一种"统一模式"即可达到 100%：**

1. **全走 if**：该 warp 内所有 `|B[i]| ≥ 7`
2. **全走 else if**：该 warp 内所有 `|B[i]| = 6`
3. **全走 else 且内层不发散**：该 warp 内所有 `|B[i]| ≤ 5`，并且要么全 `B[i] < 0`，要么全 `B[i] ≥ 0`

**答：最大利用率要求"每个 warp 内分支方向完全一致；若进入 else，还要保证 B 同号避免内层发散"。**

---

### 4) 最小 GPU 利用率（给出数值 + 构造）

为了让利用率尽量低：

- 要让 warp **执行的 slot 尽量多**（路径都出现 → 串行得更久）
- 并且让很多 slot 里**活跃线程数尽量少**（大部分 PE idle）

#### 4.1 当一个 warp 同时出现三路分支 + 内层也发散时

设一个 warp 内：

- n₁：走 `A > 0`（即 `|B| ≥ 7`）的线程数
- n₂：走 `A == 0`（即 `|B| = 6`）的线程数
- n₃：走 `A < 0`（即 `|B| ≤ 5`）的线程数
- n₁ + n₂ + n₃ = 64，且为了让内层发散，需要 n₃ ≥ 2 且其中既有 `B < 0` 又有 `B ≥ 0`。

**slot 数（发生上述所有发散时）：**

1. `A = ...`：**1 slot**
2. 判断 `if (A > 0)`：**1 slot**
3. if 分支两条语句：**2 slots**（若 n₁ > 0 才会执行）
4. 判断 `else if (A == 0)`：**1 slot**（对未进 if 的线程执行，活跃 n₂ + n₃）
5. else-if 分支语句：**1 slot**（若 n₂ > 0）
6. else 分支第一条语句：**1 slot**（若 n₃ > 0）
7. 内层判断 `if (B < 0)`：**1 slot**（若 n₃ > 0）
8. 内层 if 与 else 两条赋值：若内层发散则 **2 slots**

因此总 slot 数为：

$$S = 1 + 1 + 2 + 1 + 1 + 1 + 1 + 2 = 10$$

**busy 总和（把每个 slot 的活跃线程数相加）会化简成：**

$$\text{busy} = 256 + 2n_3$$

> **推导要点**：前两条永远 64+64；其余按分支活跃数累加，最后能消掉 n₁, n₂，只剩 n₃

于是该 warp 的平均利用率：

$$U = \frac{\text{busy}}{S \cdot 64} = \frac{256 + 2n_3}{10 \cdot 64}$$

要让 U 最小，在满足"else 存在且内层发散、三路都存在"的前提下，让 n₃ 最小即可。

内层发散要求 n₃ ≥ 2，所以取 **n₃ = 2**。

$$U_{\min} = \frac{256 + 2 \cdot 2}{640} = \frac{260}{640} = 0.40625 = 40.625\%$$

**答：最小 GPU 利用率 = 40.625%。**

#### 4.2 一种达到最小值的 B 构造（每个 warp 都这样摆）

每个 warp 的 64 个元素里这样放：

- 让 **61 个线程**走 `A > 0`：取 `B = 7`（或 -7） ⇒ `|B| ≥ 7`
- 让 **1 个线程**走 `A == 0`：取 `B = 6`（或 -6） ⇒ `|B| = 6`
- 让 **2 个线程**走 `A < 0` 且内层发散：取 `B = -1` 和 `B = +1` ⇒ `|B| ≤ 5` 且一正一负

**这样每个 warp 都会执行三路分支，并且 else 里的内层也发散，同时 else 线程数仅 2，从而达到 40.625%。**

## 总结

本题展示了包含 **else if** 的多路分支对 GPU 利用率的影响：

### 关键要点

1. **多路分支发散**：if-else if-else 结构会导致更多的串行执行路径
2. **嵌套分支**：内层分支进一步增加了发散的复杂度
3. **利用率计算**：
   - 需要统计所有可能的执行路径（slots）
   - 计算每个 slot 中活跃的线程数
   - 利用率 = 总活跃线程数 / (总 slots × warp 大小)

### 优化建议

- **最大化利用率**：确保同一 warp 内所有线程走相同的控制流路径
- **避免发散**：尽量让数据分布使得同一 warp 内的条件判断结果一致
- **减少嵌套**：嵌套的 if-else 会增加发散的可能性和严重程度

### 实际应用

在编写 GPU 代码时：

- 尽量使用数据并行而非控制流并行
- 考虑使用掩码（masking）技术替代分支
- 对输入数据进行预排序以减少 warp 内的发散
- 使用 warp 级别的原语（如 shuffle）来优化性能
