## 一. 简单流水线—考的较少
1. 不需要记住电路图，不考这个，需要知道流水线的核心思想
2. 需要知道一些原因：
	1. 为什么流水线的时钟周期 > (单周期CPU时钟周期 / 流水段个数)？
	2. 为什么流水线的CPI > 1？不能正好等于？
3. 总体来讲，流水线这块内容不多，可能会有一些涉及到常识性的东西（不用复习也能知道）。
4. 指令的相关性和危害：数据相关，控制相关，结构相关，危害大概指的是什么？哪些是真相关？哪些是假相关？

## 二. 存储层次—很重要！
1. Cache的结构：一定要好好的弄一下，要知道他是怎么设计的，他是怎么工作的，这块会有一道大题，必须得懂。
2. 概念也得懂：比如block是啥？址方式是怎么寻址的？就是映射方式有几种，比如说像直接映射的它大概是怎么工作的。
3. 另外，block内部占多少bit？索引占多少bit？tag这些都是什么？如果给一个实际的例子，需要知道他是怎么映射的。
4. 然后组相联也是比较重要，哪些是在block内部的？哪些是在组里的？组里都是随便的对吧？但是又涉及到一个替换策略。
5. 全相联就不多说了。
6. cache 主要参数的影响
	1. 你要大概知道 CACHE 的主要参数会对这个命中率有什么影响，比如说 CACHE 容量变大，它是更好的利用这个时间的局部性。右边有一个曲线，你这个 cache 越大的话，这个命中率就会越高， miss 的几率就越低。但是 CACHE 增大会增加访问延时，就是有利有弊。像这些你要知道有可能会出现在选择题或者简答题里面，像关联度这些都是比较好记的(疑似可以直接记住或者理解着记忆一下？)
	2. 但是这里面有一个比较特殊的，就是这个块儿大小的话是有正反两方面的影响，就是说你增大块儿右边那个曲线，增大块儿的话有可能会降低密度，也有可能会增加密度，所以这个你要知道增大这个 block size 不一定有正面的影响，也有可能有反面的影响。
7. 替换策略的话我们只记两种：FIFO和LRU。其他的不用管。
8. Cache传递这一块：需要知道概念，不涉及到太复杂的问题。
	1. 知道写穿透，写返回，以及他们的优缺点。
	2. 处理write miss的时候，比如写返回和写不返回，他们大概的优缺点都是什么？不需深入了解，知道这个，稍微记一下即可。
9. 对于提升Cache性能这一块（改变这个 cache 的参数会对这个 miss 的率产生什么样的影响）：
	1. 不会细致到考“增大 Cache size 会对这个哪一项产生影响”？
	2. 大概知道那个曲线就可以了

1. 记住一些概念。

	5. 虚拟内存的好处有哪些？
2. 地址转换这一块：也很简单
	1. 没有多级页表
	2. 基本就是一些比较简单的映射，就是虚拟页号到物理页号这种映射。
3. 页表。
	1. 要知道页表的结构，以及他的映射方式是什么？

4. 地址转换：TLB
	1. TLB 它缓存的是什么内容？
	2. 什么时候访问TLB？什么时候访问页表？
	3. TLB替换算法：和Cache类似，只需知道FIFO和LRU即可
5. Cache与虚拟内存并行访问：不太涉及！
6. TLB miss
	1. 就是刚刚说的什么时候什么时候访问TLB，什么时候访问页表
	2. 基于硬件的访问方式和基于软件的访问方式，优缺点是什么？
	3. 缺页异常：知道什么意思
